# Day 1 Notes: Terminal & Git

## Terminal Commands
1. **pwd**: Prints the working directory path.
2. **ls -la**: Lists all files including hidden ones with details.
3. **cd <folder>**: Changes into a specified directory.
4. **mkdir <name>**: Creates a new folder.
5. **clear**: Clears the terminal screen display.

## Git Commands
1. **git init**: Initializes a local Git repository.
2. **git status**: Displays untracked, modified, and staged changes.
3. **git commit -m "..."**: Saves a snapshot of staged changes with a descriptive message.
